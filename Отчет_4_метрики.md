## Домашнее задание №4. Метрики

### Стек реализации

| Компонент | Технология |
|---|---|
| Язык и платформа бэкенда | Java 22 |
| Фреймворк бэкенда | Spring Boot 3.3.4 (Spring Web, Spring Data JPA, Spring Security, Bean Validation) |
| ORM | Hibernate (Spring Data JPA) |
| СУБД | PostgreSQL 16 |
| Миграции схемы БД | Liquibase |
| Сборка бэкенда | Maven |
| Фронтенд | Статическая HTML-страница на JavaScript |

### Использованные экспортеры
Метрики эскпортируются по pull модели: веб-приложение реализует отдельный URL. 

Бд - `/metrics`, бэк - `/actuator/prometheus`

В проекте для мониторинга использовались `Postgres Exporter` и встроенные средства `Spring Boot Actuator` с `Micrometer`. Для хранения и получения метрик использовалась система `VictoriaMetrics`.

Для метрик рантайма - также `Spring Boot Actuator` с `Micrometer`

### Реализованные бизнес-метрики

| Метрика | Описание |
|---|---|
| users_registered_total | регистрации пользователей |
| notes_findAll_total | запросы на получение своих заметок |
| notes_created_total | создания заметок |
| notes_updated_total | обновления заметок |
| notes_deleted_total | удаления заметок |
