## Домашнее задание №2. Основы Kubernetes

### Используемые абстракции

- **Deployment** — управляет наборами подов фронтенда, бэкенда и Postgres: следит за числом реплик и обновляет поды. Для stateless-сервисов используется RollingUpdate, для Postgres — Recreate.
- **Service** — стабильное имя и IP для группы подов, выбор подов по labels:
  - `note-service-backend` (ClusterIP, порт 8080);
  - `postgres` (ClusterIP, порт 5432);
  - `note-service-frontend` (NodePort, порт 80) — точка входа снаружи.
- **ConfigMap** — несекретные настройки бэкенда (URL базы, имя пользователя, порт) и бд.
- **Secret** — пароли для бэкенда и Postgres.
- **PersistentVolumeClaim** — запрос хранилища для данных Postgres, чтобы они переживали пересоздание пода.

### Взаимодействие сервисов


- **Фронтенд** отдаёт статические файлы через nginx. Адрес бэкенда передаётся переменной `BACKEND_URL` и подставляется в `proxy_pass` при старте контейнера.
- **Бэкенд** (Spring Boot) обращается к базе по имени сервиса `postgres`. Настройки берутся из ConfigMap, пароль — из Secret.
- **Postgres** доступен только внутри кластера через сервис `postgres`.
- Браузер напрямую к бэкенду и базе не обращается: все запросы идут через фронтенд.
